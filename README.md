# Dj Ape1 — εφαρμογή για Windows 10/11

Παράγονται δύο αρχεία στον φάκελο `dist`:
- **DjApe1-Setup-2.2.1.exe** — εγκατάσταση (Start Menu, συντόμευση, απεγκατάσταση, "Άνοιγμα με…" για αρχεία ήχου). Δεδομένα στο `%AppData%\dj-ape1`.
- **DjApe1-Portable-2.2.1.exe** — χωρίς εγκατάσταση. Βιβλιοθήκη και ρυθμίσεις στον φάκελο `DjApe1-data` δίπλα στο .exe.

## Τι περιλαμβάνει
- **Φάκελοι:** ανάγνωση απευθείας από τα Windows, χωρίς άδειες, γρήγορη σάρωση, tags και διάρκεια από το σύστημα αρχείων, αυτόματη ανίχνευση νέων αρχείων.
- **Βιβλιοθήκη στον δίσκο** (`library\library.json`) με ατομική εγγραφή και **αυτόματα αντίγραφα ασφαλείας** (τα 5 τελευταία). Χαλασμένο αρχείο → φορτώνεται το πιο πρόσφατο υγιές αντίγραφο. Επαναφορά: ⚙ Διαχείριση → Δεδομένα → "Επαναφορά…".
- **Windows:** πλήκτρα πολυμέσων, κουμπιά στη γραμμή εργασιών, εικονίδιο tray, κλείσιμο στο tray, έναρξη με τα Windows (⚙ Παραμετροποίηση οθόνης → Windows), "Άνοιγμα με Dj Ape1".
- **Full screen:** κουμπί ⛶ στη πάνω μπάρα (και F11) για ολόκληρο το πρόγραμμα· ξεχωριστό από το full screen του τραγουδιού.
- **Ήχος:** επιλογή κάρτας ήχου και Audiophile mode στο μενού 🔊 Ήχος.
- **Έξυπνες playlists με κανόνες:** ✨ δίπλα στο ＋ των Playlists στο πλάι, ή το ✨ στην πάνω μπάρα (δουλεύει και με κρυμμένο πλαϊνό πάνελ) → κανόνες για είδος, καλλιτέχνη, τίτλο, άλμπουμ, έτος, BPM, key (και αρμονική ταύτιση), διάρκεια, φορές αναπαραγωγής, τελευταία αναπαραγωγή, αρχείο· "όλοι οι κανόνες" ή "οποιοσδήποτε". Επεξεργασία με το ⚙ Κανόνες.
- **🔮 Πρόταση επόμενου τραγουδιού** (πάνω μπάρα): βαθμολογεί τη βιβλιοθήκη με αρμονικό key (Camelot), BPM, είδος και πρόσφατη ακρόαση· ▶ παίζει, ⏭ βάζει επόμενο, ➕ στην ουρά. Προαιρετικό **Auto DJ** όταν τελειώνει η ουρά. Για καλύτερες προτάσεις τρέξε την ανάλυση key/BPM.
- **🧠 Smart Mix** (πάνω μπάρα, ή 🧠 Mix σε κάθε playlist): σαν το Automix αλλά πιο έξυπνο. Διαλέγεις πηγή (βιβλιοθήκη, playlist ή οι κανόνες που ετοίμασες), είδη, εύρος BPM, διάρκεια, **ροή ενέργειας** (σταθερή, ανοδική, καθοδική, κύμα) και **αρμονία key**. Κάθε επόμενο τραγούδι επιλέγεται με key, BPM, είδος, ποικιλία καλλιτεχνών και τι άκουσες πρόσφατα, και βλέπεις την ποιότητα κάθε μετάβασης. Παίζει με crossfade ή αποθηκεύεται ως playlist.
- **📚 Βιβλιοθήκη** (πάνω μπάρα): ένα παράθυρο για όλα — κατάσταση, φάκελοι, **Συγχρονισμός φακέλων** (επανασύνδεση + νέα + συγχώνευση αντιγράφων), προσθήκη φακέλου, εισαγωγή/εξαγωγή αρχείου, καθαρισμός διπλότυπων, νέα βιβλιοθήκη (με αντίγραφο ασφαλείας).
- **Διπλότυπα:** αναγνωρίζονται με όνομα+μέγεθος, με καλλιτέχνη+τίτλο+διάρκεια και με τίτλο+διάρκεια όταν λείπει ο καλλιτέχνης. Μετά από κάθε σάρωση τα νέα αντίγραφα συγχωνεύονται αυτόματα στο υπάρχον τραγούδι (κρατούνται στοιχεία, ακροάσεις, playlists). Τα αρχεία στον δίσκο δεν διαγράφονται ποτέ.
- **⧉ Μικρό παράθυρο** (πάνω μπάρα, Ctrl+Shift+M ή tray): μικρός player που μένει πάντα από πάνω.
- **🎨 Θέματα:** 9 θέματα (Σκούρο, Φωτεινό, Midnight, Forest, Crimson, Violet, AMOLED, Sunset, Mint).

## Χτίσιμο
### Τρόπος 1 — GitHub (χωρίς να εγκαταστήσεις τίποτα)
1. Φτιάξε ένα (ιδιωτικό) repository και ανέβασε **όλο το περιεχόμενο** αυτού του φακέλου, μαζί με τον κρυφό φάκελο `.github`.
2. Καρτέλα **Actions → Build Windows → Run workflow**. Σε ~5-10 λεπτά κατεβάζεις τα δύο .exe από τα **Artifacts**.
3. Για Release: δημιούργησε tag, π.χ. `v2.2.1` — τα .exe επισυνάπτονται αυτόματα.

### Τρόπος 2 — στον υπολογιστή σου (Node.js LTS)
Διπλό κλικ στο `build.bat` (ή `npm install` και `npm run dist`). `npm start` τρέχει την εφαρμογή χωρίς build, `npm test` τα τεστ.

## Αντιμετώπιση προβλημάτων
- **"Cannot create symbolic link … privilege" στο build:** τα Windows μπλοκάρουν symlinks. Το `build.bat` δοκιμάζει αυτόματα build χωρίς επεξεργασία εικονιδίου. Για το δικό σου εικονίδιο: Ρυθμίσεις → Για προγραμματιστές → Developer Mode ON, διαγραφή του `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign` και νέο build.
- Ακόμα κι αν αποτύχει το packaging, ο φάκελος `dist\win-unpacked` περιέχει λειτουργικό πρόγραμμα (`Dj Ape1.exe`).
- Το μήνυμα npm `install-scripts … electron` είναι προειδοποίηση. Αν το `npm start` πει ότι λείπει το Electron: `node node_modules\electron\install.js`.

## Αν το GitHub Actions γράφει "Could not read package.json"
Το workflow βρίσκει πλέον μόνο του τον φάκελο του project. Αν παρ' όλα αυτά γράψει ότι λείπει το `package.json`, δεν ανέβηκαν όλα τα αρχεία. Στο repository (κεντρική σελίδα) πρέπει να φαίνονται: `.github`, `app`, `assets`, `build`, `tests`, `main.js`, `native.js`, `preload.js`, `package.json`, `README.md`. Ανέβασε ξανά το **περιεχόμενο** του zip (αφού το αποσυμπιέσεις), όχι το ίδιο το zip.

## Αν η εφαρμογή «κολλήσει» ή γίνει μαύρη
- Η αναζήτηση στο web είναι πλέον «ευγενική»: όσο παίζει μουσική δεν ξαναζωγραφίζει τη λίστα, αραιώνει τις αποθηκεύσεις και περιμένει όταν η εφαρμογή καθυστερεί.
- Αν η σελίδα σκάσει ή κολλήσει, το πρόγραμμα το καταγράφει, ανακτά μόνο του τη βιβλιοθήκη και φορτώνει ξανά. Αν κολλήσει, ρωτά αν θες αναμονή ή επαναφόρτωση.
- Μαύρη οθόνη συνήθως σημαίνει πρόβλημα GPU: μετά από 2 σφάλματα GPU το πρόγραμμα περνά αυτόματα σε λογισμικό. Μπορείς να το αλλάξεις και χειροκίνητα από το tray → «Επιτάχυνση GPU».
- Αρχείο διαγνωστικών: ⚙ Διαχείριση → Δεδομένα → «Αρχείο διαγνωστικών → Εμφάνιση» (`diagnostics.log`). Αν ξανασυμβεί, στείλε μου αυτό το αρχείο.
